# MiKo_3240: Do not declare return variables before an early return

## Cause

A method declares its return variable as the first statement.
The next statement is an `if` block that only returns that variable.

## Rule description

Do not declare the return variable at the start of a method if the next if block only returns it.
Readers have to look up the variable to see which value is returned, and the variable lives longer than needed.
Return the value directly and declare the variable later, when it is needed.

## Rationale behind

A variable that is declared at the start of a method and only returned in an early `if` block is hard to read.
The reader sees the `return` statement, but the returned value is not obvious there.
The reader has to go back to the variable declaration to find out which value is returned.

The variable is also created before it is needed.
Its lifetime is longer than necessary, and it adds mutable state to the method, although the early return only returns a known value.

Following this rule provides several important benefits:

- **Better Readability**:
  The returned value is visible directly at the `return` statement.
  Readers do not need to look up a variable to understand what the method returns.

- **Less Indirection**:
  Without the local variable, there is one less name to remember and follow.
  The code says directly what it does.

- **Shorter Variable Lifetime**:
  The variable is declared close to the place where it is really needed.
  This makes it clear which part of the method uses it.

- **Less Mutable State**:
  The method does not introduce state at the beginning that is not used by the early return.
  This reduces the chance of accidental changes to the variable.

- **Clearer Control Flow**:
  The early return becomes simple and easy to follow.
  Readers see at once what happens in each path of the method.

## How to fix violations

To fix a violation of this rule, return the value directly in the `if` block.
Move the declaration of the variable to the place after the `if` block, where it is first needed.

## How to suppress violations

```csharp
#pragma warning disable MiKo_3240
#pragma warning restore MiKo_3240
```
