# MiKo_6082: Surround local functions with blank lines

## Cause

A local function is not surrounded by blank lines.

## Rule description

Surround local functions with blank lines to visually separate them from other code.
This improves readability and makes the code easier to follow.

## Rationale behind

A local function is a separate piece of logic that lives inside another method.
When it directly touches the surrounding statements, it is hard to see where the normal code ends and where the local function starts.
Blank lines before and after the local function make this boundary visible.

Surrounding local functions with blank lines provides several important benefits:

- **Improved Readability**:
  Blank lines separate the local function from the other code.
  Developers can quickly see which lines belong to the local function and which do not.

- **Clearer Structure**:
  The method body is split into clear parts.
  The statements of the method and the local functions are easy to tell apart.

- **Easier Navigation**:
  Developers who scan through a method can spot the local functions at a glance.
  This helps to find the code that is needed.

- **Consistent Code Style**:
  A common layout for local functions makes the code look the same across the code base.
  This reduces the effort needed to read code written by others.

## How to fix violations

To fix a violation of this rule, add a blank line before and after each local function.

## How to suppress violations

```csharp
#pragma warning disable MiKo_6082
#pragma warning restore MiKo_6082
```
