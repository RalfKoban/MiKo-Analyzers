# MiKo_3244: Replace complex anonymous methods with named methods

## Cause

An anonymous method contains too many lines of code or is too complex.

## Rule description

To make code easier to read and maintain, anonymous methods should be kept short.
Long anonymous method bodies are difficult to understand and often deserve a meaningful name.
Consider replacing the anonymous method with a named method.

## Rationale behind

Long anonymous methods are difficult to understand, test, and maintain.
They are written inline, so the surrounding code is mixed with the details of the anonymous method body.
This makes it harder to see what the code around the anonymous method is doing.

Moving the body into a named method gives the logic a clear name and a clear place.

Keeping anonymous methods small provides several important benefits:

- **Improved Readability**:
  Short anonymous methods can be understood at a glance.
  The code around them stays easy to follow.

- **Easier Testing**:
  A named method can be tested on its own.
  An anonymous method body that is written inline can only be tested through the code that contains it.

- **Better Maintainability**:
  Changes are easier to make when the logic is in a separate method with a single purpose.
  Changes are also less likely to break something else.

- **Clearer Intent**:
  A good method name tells what the code does.
  The code inside the method shows how it works.

- **Easier Debugging**:
  Named methods are easier to find in stack traces.
  Breakpoints are also easier to set and follow.

- **Enhanced Reusability**:
  A named method can be used in other places.
  This means less duplicate code needs to be written.

## How to fix violations

To fix a violation of this rule, move the body of the anonymous method into a separate named method.
Give the method a meaningful name that describes what it does.

The anonymous method can then be replaced by a call to that method.

## How to suppress violations

```csharp
#pragma warning disable MiKo_3244
#pragma warning restore MiKo_3244
```
