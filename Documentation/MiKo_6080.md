# MiKo_6080: Align block braces vertically

## Cause

The opening and closing braces of a block are not placed in the same column.

## Rule description

Code readability improves when the opening and closing braces of a block are vertically aligned.
This makes the structure of the code easier to recognize and easier to follow.

## Rationale behind

Braces define where a block of code starts and ends.
When the opening and closing braces are in different columns, it is harder to see which brace belongs to which block.
This makes the code harder to read and increases the risk of mistakes.

Aligning the braces vertically provides several important benefits:

- **Improved Readability**:
  Matching braces in the same column show the scope of a block at a glance.
  Developers do not need to search for the brace that closes a block.

- **Easier Navigation**:
  Developers can follow a vertical line from the opening brace to the closing brace.
  This helps to find the start and end of nested blocks quickly.

- **Fewer Mistakes**:
  Missing or misplaced braces are easier to spot when the layout is consistent.
  This reduces errors when code is changed or new statements are added to a block.

- **Consistent Code Style**:
  A uniform brace layout makes all code in a code base look the same.
  This helps developers to feel familiar with code written by others.

- **Simpler Code Reviews**:
  Reviewers can focus on the logic instead of the formatting.
  Structural problems are visible more quickly.

## How to fix violations

To fix a violation of this rule, place the opening and closing braces of the block in the same column.

## How to suppress violations

```csharp
#pragma warning disable MiKo_6080
#pragma warning restore MiKo_6080
```
