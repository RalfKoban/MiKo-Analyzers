# MiKo_3237: Use using directives instead of fully qualified names

## Cause

A type is referenced by its fully qualified name, even though a using directive could be added instead.

## Rule description

Qualified names can make code longer and harder to read.
Use using directives when referencing types to keep the code short and easier to understand.
This helps improve code readability and reduces visual noise.

### Rationale behind

Fully qualified names repeat the complete namespace path every time a type is used.
This adds extra characters that do not carry much meaning for the reader.
It also makes lines longer, which can force code to wrap or scroll horizontally.

A using directive is added once at the top of the file.
After that, the type can be used with its short name everywhere in the file.
The reader only sees the part of the name that matters, without the surrounding noise.

Using a using directive instead of a fully qualified name provides several important benefits:

- **Improved Readability**:
  Shorter names are easier to read and scan.
  The reader can focus on the logic of the code instead of parsing long namespace paths.

- **Reduced Visual Noise**:
  Long qualified names clutter the code.
  A using directive removes this clutter and keeps the code clean.

- **Shorter Lines**:
  Fully qualified names can make lines very long.
  A using directive keeps lines short, which reduces the need for wrapping or horizontal scrolling.

- **Easier Maintenance**:
  When a using directive is added once, it can be reused everywhere in the file.
  Changes to the namespace only need to be made in one place.

- **Consistency**:
  Code that consistently uses short type names is easier to compare and review.
  Mixing fully qualified names with short names makes the code look inconsistent.

## How to fix violations

To fix a violation of this rule, add a using directive for the namespace of the type at the top of the file.
Then replace the fully qualified name with the short type name.

## How to suppress violations

```csharp
#pragma warning disable MiKo_3237
#pragma warning restore MiKo_3237
```
