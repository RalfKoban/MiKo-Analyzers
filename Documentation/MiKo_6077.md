# MiKo_6077: Place short parameter lists on single line

## Cause

A parameter list is unnecessarily split across multiple lines.

## Rule description

Parameter lists that span multiple lines but contain zero or only one parameter are more difficult to read.
Keep them on a single line to make the code easier to read and follow.

## Rationale behind

A parameter list is the part in parentheses after a method name, such as `(string name)`.
When it contains no parameter or only one parameter, it is short and easy to read on a single line.

Splitting such a list across multiple lines wastes space and makes the code look more complex than it is.
It also separates the parameter from the method name it belongs to.

Keeping short parameter lists on a single line provides several important benefits:

- **Improved Readability**:
  A short parameter list on a single line can be read at a glance.
  There is no need to scan multiple lines to find the parameter.

- **Reduced Visual Clutter**:
  Single-line parameter lists use less vertical space.
  This allows more code to be visible on the screen at once.

- **Clear Association**:
  The parameter stays next to the method name.
  This makes it obvious which parameter belongs to which method.

- **Consistent Code Style**:
  Short parameter lists look the same everywhere in the code base.
  This helps developers to find their way around the code faster.

- **Easier Code Maintenance**:
  Parameter lists on a single line are easier to change.
  Differences in code reviews are also smaller and easier to understand.

## How to fix violations

To fix a violation of this rule, move the parameter list onto a single line.
Ensure that the parameter follows directly after the name of the method.

## How to suppress violations

```csharp
#pragma warning disable MiKo_6077
#pragma warning restore MiKo_6077
```
