# MiKo_6074: Align multi-line string concatenations vertically

## Cause

A string concatenation that spans multiple lines contains `+` operators that are not vertically aligned with each other.

## Rule description

Code readability improves when string concatenations are aligned vertically.
This makes the concatenation clearer and easier to follow.

### Rationale behind

A long string concatenation is often split across several lines.
Without a consistent alignment, the `+` operators can end up at different columns.
This makes it hard to see where one part of the string ends and the next one begins.

Keeping multi-line string concatenations vertically aligned provides several important benefits:

- **Improved Readability**:
  When every `+` operator starts at the same column, the concatenation reads like a structured list of parts.
  This makes it easier to understand what the final string looks like without carefully parsing each line.

- **Easier Scanning**:
  Aligned operators allow a reader to quickly identify how many parts are concatenated and where each part starts.

- **Reduced Cognitive Load**:
  A consistent visual structure needs less mental effort to parse.
  This is especially helpful for developers who are less familiar with the code.

- **Better Maintainability**:
  A consistently formatted concatenation is easier to change.
  Adding, removing, or reordering parts is straightforward when each line follows the same indentation pattern.

- **Consistent Code Style**:
  Uniform formatting across all string concatenations in a codebase creates a predictable style that every team member can rely on.

## How to fix violations

To fix a violation of this rule, adjust the indentation of the misaligned lines so that all `+` operators start at the same horizontal position.

## How to suppress violations

```csharp
#pragma warning disable MiKo_6074
#pragma warning restore MiKo_6074
```
