# MiKo_6079: Align anonymous method blocks vertically with the delegate keyword

## Cause

The block of an anonymous method expression does not start at the same indentation level as the delegate keyword.

## Rule description

Code readability improves when the block of an anonymous method expression starts at the same indentation level as the delegate keyword.
Misaligned braces make the anonymous method harder to recognize and disrupt the visual structure of the code.

Vertically aligning the block with the beginning of the delegate keyword makes the anonymous method easier to read and understand.

## Rationale behind

An anonymous method consists of the delegate keyword followed by a block.
When the block starts at a different indentation level than the delegate keyword, it is harder to see where the anonymous method begins and ends.
This makes the code harder to read and increases the risk of mistakes.

Aligning the block with the delegate keyword provides several important benefits:

- **Improved Readability**:
  The block and the delegate keyword form a clear visual unit.
  Developers see the scope of the anonymous method at a glance.

- **Easier Navigation**:
  Developers can follow a vertical line from the delegate keyword to the closing brace.
  This helps to find the start and end of the anonymous method quickly.

- **Fewer Mistakes**:
  Misplaced or missing braces are easier to spot when the layout is consistent.
  This reduces errors when code is changed.

- **Consistent Code Style**:
  A uniform layout makes all code in a code base look the same.
  This helps developers to feel familiar with code written by others.

- **Simpler Code Reviews**:
  Reviewers can focus on the logic instead of the formatting.
  Structural problems are visible more quickly.

## How to fix violations

To fix a violation of this rule, place the block of the anonymous method at the same indentation level as the delegate keyword.

## How to suppress violations

```csharp
#pragma warning disable MiKo_6079
#pragma warning restore MiKo_6079
```
